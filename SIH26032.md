# KisanSewa — SIH 26032

## Problem Statement (Inferred from App + Master Prompt)
A smart procurement queue management system for farmers and mandi admins.

## Core Features Implemented
- User Authentication (Firebase Auth) — Login screen added
- Farmer Dashboard — Mandi list with capacity indicators, book slot
- Booking Form — Select mandi, crop, quantity, date/time, validation
- Token Generation — QR code token with status tracking (Booked → Reached → Weighed → Paid)
- Admin Dashboard — Live stats, mandi overview, recent tokens
- Admin Scanner — QR scan with camera permission, manual entry fallback
- State Management — Zustand store (`store/useStore.js`)
- Navigation — expo-router file-based routing (`_layout.js`)
- Animations — react-native-reanimated spring/delay animations on all screens
- Styling — NativeWind (Tailwind CSS) configured
- Firebase SDK — Auth, Firestore, Storage initialized (`app/config/firebase.js`)
- Backend — Express + Firebase Admin (`backend/index.js`)
- Image Upload — Component using Firebase Storage (`components/ImageUploader.js`)

## Compatibility (Expo SDK 54)
- react-native-reanimated ~4.1.1
- react-native-gesture-handler ~2.28.0
- react-native-screens ~4.16.0
- nativewind + tailwindcss v3
- All verified for New Architecture

## Setup
`npm install`
`npx expo start`

For backend:
